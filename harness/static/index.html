Procurement Audit Planner · West Berkshire Council

A hosted agent harness that plans an internal audit of procurement from public data. It extracts the purchasing rules, analyses the full spend population, reads past audit history, rates the risks, stops for the auditor's approval, and runs a three-agent team to build and cross-check the audit planning pack before sign-off. Outputs are risk indicators to investigate, not findings of wrongdoing.

How it works

The harness runs the project's own Claude Code skills and agents (.claude/skills, .claude/agents) with the Claude Agent SDK on a server, against a workspace copy of the public data. Every number comes from Python the agents write and run; every quote, figure and sampled transaction is re-checked by scripts.

  1. extract-rules (skill): Contract Procedure Rules PDF → rules.json, quotes verified word for word.
  2. spend-analyst + findings-analyst (sub-agents, in parallel): three months of spend + Contracts Finder notices → analytics.json; Governance Committee papers → history.json.
  3. risk-assessor (sub-agent + risk-assessment skill): cited likelihood × impact ratings on the council's own scale → risk-register.md and the auditor's decision template.
  4. Human gate: the auditor approves / amends / rejects each risk here; the risk-assessor builds the next revision.
  5. Agent team: planner builds the pack (memo, risk-control matrix, audit program, targeted samples); challenger challenges weak spots for up to two rounds; qa-reviewer runs the four check scripts and blocks sign-off until all pass. The teammates message each other through a tool the harness provides; the harness is the lead.
  6. Human gate: the auditor reads the review and the challenger's points for the auditor, then signs off or returns the pack.
