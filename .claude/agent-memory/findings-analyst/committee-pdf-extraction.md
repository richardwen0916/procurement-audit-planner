How-to lessons for extracting committee papers (learned 2026-10-15). Not evidence; re-read the PDFs every run.

- **Completed-work appendices: plain text breaks table rows.** Row cells get split by directorate headings, so some title/opinion pairs are not adjacent. Read rows from the `-layout` text; quote "Title Opinion" only when it is contiguous in plain text, otherwise quote the title alone (or the contiguous fragment) and add an `extraction_note`. **Why:** verifier matches against plain pdftotext. **How to apply:** for every row, check adjacency in plain text before choosing the quote.
- **Verifier normaliser does NOT strip ASCII hyphens** (corrected 2026-10-17; an earlier note said it did). Its BULLET_RE is a private-use range U+E000–U+F8FF plus • ▪ ● ⁃ …; en/em dashes become "-" and stay. So keep "-" wherever plain text prints it (e.g. "Actual level - this", "15 -25"); bullets may be dropped. Quotes must be ≥12 chars: quote a short cell (e.g. a one-word cell) together with the next cell. **How to apply:** in the build script, import `normalise` from scripts/verify_history.py instead of re-implementing it, so the pre-check cannot drift from the verifier.
- **Strategy tables:** Table 1 (impact) and Table 3 (appetite) garble in plain text but each cell's text survives contiguously; quote cell by cell. Table 3 spans two pages, and a cell can straddle the boundary: quote the part on one page. Table 3 marks the appetite by shading, which text extraction loses, so take the set levels from the 5.10 statements.
- **Strategy page numbers:** the printed page equals the PDF page from the Appendix A cover onward; the covering-report pages print none. Appendix 1 (policy) restarts section numbering, so label it "Appendix 1, x.y".
- **Plan covering report** is the covering report only. Its appendices are listed in section 8 but not included. It prints no page numbers, so cite sections.
- **Known absent:** Corporate/Strategic Risk Register (exempt), plan Appendices A–F, and the covering reports for the completed-work appendices. No paper lists individual agreed actions.
- Building history.json from a Python script in the scratchpad (helper that makes a source/page/quote dict) works well. Better (2026-10-17): have the helper normalise like the verifier, search all pages for the quote and fail on 0 or >1 hits. That catches bad quotes before the verifier runs.
- **Contiguous fragments that verify (2026-10-17):** in Table 1 plain text, "score label financial-cell" is contiguous per row (e.g. "N Label <budget share> <£ band>"). Table 2 prints all labels first, then the definitions, then the probabilities, so quote labels and probabilities as two strings and give each definition its own quote. Figure 1 rows come out as "5 labels then 5 scores", top row first, with no impact label; take the row alignment from the layout text. If a cell is under 12 chars (e.g. a one-word cell), quote it together with the next cell in plain-text order.
- **Plan 5.7 (a)-(e):** plain text prints all the "(a) (b) (c) (d) (e)" markers before the item texts, so quote in that order. Section 5.6(b) mentions monitoring of agreed recommendations but lists none.
- **Update 2026-10-19:** plan covering report is 7 pages (plain text gives an empty 8th chunk); 4.2 text repeats on pages 1/3/4, so pass an explicit page for quotes that recur. Plain text of Table 2 places 'Rare' probability ('–<2%') away from the other probabilities: quote the first four only. Verifier hyphen handling may differ from the note above, so always import `normalise` from verify_history.py (this run's helper did and avoided the question). Table 4 '(Amber)' belongs to the 8-12 row per the layout text, although plain text puts it next to Moderate. Table 1 'Death' cell is <12 chars: quote it with the next cell.
- **Update 2026-10-19 (b):** verifier requires `scoring_method.evaluation_levels` as a LIST of {level, definition, source, pdf_page, quote}; an object keyed by level fails. A pre-existing history.json may fail only on shape: convert, then re-verify.
